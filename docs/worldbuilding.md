# hatyibei 世界観メモ

ポータルサイトを作るためのヒアリング記録。見た目や機能を決めるときは、まずここに立ち返る。

## 核

> **hatyibei の頭の中の世界（パラコズム）を、住民ごと具体化した場所。**
> 7歳の夜、画面の向こうに見た「誰かが暮らす世界」を、今度は自分で作っている。

AI に本気になった理由：**頭の中の世界を具体にできることに感動した。**

## 世界

| 要素 | 内容 |
|---|---|
| 舞台 | 山と森。空気が澄んでいる。**宇宙・ロボットは不要** |
| 住民 | 村人、動物、精霊、気配だけのもの（＝生態系） |
| 時間 | 朝が一番好き、夜も好き。時間が巡り、手をかけたものが育つ |
| 主人公 | 八兵衛。町を歩く現場の人。情にもろく、直感で動く（≒ Forward Deployed Engineer） |
| 表現 | **水墨**。霧は描かない余白。形式は**絵巻**（右から左へ、時間に沿って旅する） |

## ルール

- **遊び心と、自分が楽しいことが最優先。** 牧場のように、戻ってきて何かを植えたくなる構造にする
- **言うな、見せろ。** 「自分は〇〇です」と語るパーツ（トロフィー、スキル一覧、モットー）で語らない。作ったものを世界の中の「場所」として置く
- 隠し要素を入れる（例：最強防具 → BAN）

## 誰のため

一番は自分（自分の世界の置き場所）。そこへ旅人として、エンジニア仲間・採用担当・教えた相手が訪れる。
急いでいる旅人のために「旅人の手帳」（ふつうの経歴一覧）を用意する。
